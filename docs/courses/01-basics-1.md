# Модуль 1. Основы 1: Кирпичики языка

> Учебные фрагменты сокращены и показывают отдельный принцип; полный актуальный код открывайте по указанным исходникам. Примеры Item/Product и товарных документов не означают наличия этих модулей в текущем контенте.

> В этом модуле мы разберём базовые конструкции Go и сразу проведём параллели с платформой 1С:Предприятие. После прочтения вы будете уверенно читать 80% кода Metapus.

## 1. Программа на Go: минимальный скелет

Каждая программа на Go начинается с пакета `main` и функции `main()`:

```go
package main          // 1. Указываем пакет (в 1С аналога нет)

import "fmt"          // 2. Подключаем библиотеку форматированного вывода

func main() {         // 3. Точка входа — как «ПриНачалеРаботыСистемы()»
    fmt.Println("Привет, Metapus!")
}
```

Запуск:
```bash
go run main.go        # Скомпилирует и запустит
go build main.go      # Скомпилирует в бинарник ./main (или main.exe на Windows)
```

## 2. Типы и Переменные

В 1С переменные динамически типизированы: `Перем Сумма;` может хранить и число, и строку. В Go типизация **строгая и статическая** — компилятор проверяет типы ДО запуска.

### Основные типы

| Go тип | Описание | Аналог в 1С | Нулевое значение |
|--------|----------|-------------|-----------------|
| `int` | Целое число | `Число` (без дробной части) | `0` |
| `float64` | Дробное число | `Число` (с дробной частью) | `0.0` |
| `string` | Строка | `Строка` | `""` (пустая строка) |
| `bool` | Логический | `Булево` | `false` |

### Объявление переменных

```go
// Способ 1: Полное объявление (явный тип)
var count int = 10
var name string = "Документ Продажа"

// Способ 2: Тип опускается, Go догадается сам (вывод типа)
var isActive = true   // Go поймёт, что это bool

// Способ 3: Краткое объявление через := (только внутри функций!)
sum := 1500.50        // автоматически float64
code := "000000001"   // автоматически string
```

### Нулевые значения (Zero Values) — критичная концепция!

В 1С необъявленная переменная имеет значение `Неопределено`. В Go **каждый тип** имеет конкретное нулевое значение. Это не `nil` и не «пусто» — это реальное значение:

```go
var num int       // 0
var name string   // "" (пустая строка)
var ok bool       // false
var price float64 // 0.0

fmt.Println(num, name, ok, price)
// Выведет: 0  false 0
```

> [!IMPORTANT]
> **Почему это важно для Metapus:**
> Мы используем нулевые значения осознанно. Например, в enum'ах `iota + 1` (Правило §2.10) — нулевое значение `0` означает «статус не задан», и это ловит ситуацию, когда программист забыл указать статус. В 1С `Неопределено` приведёт к ошибке только в рантайме, а в Go компилятор поймает проблему ещё ДО запуска.

## 4. Условия: if / else

В 1С: `Если ... Тогда ... ИначеЕсли ... Иначе ... КонецЕсли`. В Go:

```go
amount := 1500

if amount > 1000 {
    fmt.Println("Крупная сумма")
} else if amount > 100 {
    fmt.Println("Средняя сумма")
} else {
    fmt.Println("Мелкая сумма")
}
```

**Особенность Go:** в `if` можно объявить переменную, которая будет жить ТОЛЬКО внутри блока:

```go
if err := doSomething(); err != nil {
    fmt.Println("Ошибка:", err)
    // err существует здесь
}
// err здесь уже НЕ существует — компилятор выдаст ошибку
```

Это **самый частый паттерн** в Go. Вы будете встречать его в каждом файле Metapus.

## 5. Switch

В 1С нет прямого аналога `switch`. В Go он мощнее, чем в большинстве языков — не нужен `break`, Go автоматически выходит после первого совпадения:

```go
status := "posted"

switch status {
case "draft":
    fmt.Println("Черновик")
case "posted":
    fmt.Println("Проведён")
case "deleted":
    fmt.Println("Удалён")
default:
    fmt.Println("Неизвестный статус")
}
```

Switch без условия (аналог цепочки `if/else if`):

```go
amount := 1500
switch {
case amount > 10000:
    fmt.Println("VIP")
case amount > 1000:
    fmt.Println("Стандарт")
default:
    fmt.Println("Эконом")
}
```

## 6. Циклы: for

В 1С есть `Для`, `Для Каждого`, `Пока`. В Go есть только **один** цикл — `for`. Но он умеет всё:

```go
// Классический (аналог «Для Сч = 0 По 4 Цикл»)
for i := 0; i < 5; i++ {
    fmt.Println(i)
}

// Аналог «Пока» (while)
n := 1
for n < 100 {
    n = n * 2
}

// Бесконечный цикл (выход через break)
for {
    fmt.Println("работаю...")
    break  // без break — будет крутиться вечно
}

// continue — пропуск итерации
for i := 0; i < 10; i++ {
    if i%2 == 0 {
        continue  // пропускаем чётные
    }
    fmt.Println(i) // напечатает 1, 3, 5, 7, 9
}
```

### range — перебор коллекций (аналог «Для Каждого»)

```go
names := []string{"Иванов", "Петров", "Сидоров"}

for index, name := range names {
    fmt.Printf("Строка %d: %s\n", index, name)
}
// Строка 0: Иванов
// Строка 1: Петров
// Строка 2: Сидоров
```

Если индекс не нужен, используйте `_`:

```go
for _, name := range names {
    fmt.Println(name)
}
```

## 7. Функции и Множественный возврат

В 1С есть Процедуры (не возвращают значение) и Функции (возвращают одно значение). В Go функции могут возвращать **несколько значений** — это фундамент обработки ошибок.

```go
// Функция с одним возвратом (как Функция в 1С)
func add(a, b int) int {
    return a + b
}

// Функция с двумя возвратами — САМЫЙ ЧАСТЫЙ ПАТТЕРН В GO
func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("деление на ноль")
    }
    return a / b, nil  // nil = нет ошибки
}

func main() {
    result, err := divide(10, 3)
    if err != nil {
        fmt.Println("Ошибка:", err)
        return
    }
    fmt.Println("Результат:", result)
}
```

> [!WARNING]
> **Запомните этот паттерн: `value, err := someFunc()` + `if err != nil`.**
> Вы будете видеть его буквально на каждой странице кода Metapus. Если функция может завершиться ошибкой, она ВСЕГДА возвращает `error` последним значением.

## 8. Указатели (Pointers)

В 1С объекты (СправочникОбъект, ТаблицаЗначений) передаются «по ссылке» неявно. В Go **всё** передаётся по значению (копируется), если вы явно не передали **указатель**.

Указатель — это адрес переменной в памяти. Два оператора:
- `&x` — получить адрес переменной `x` (дай мне указатель)
- `*p` — получить значение по указателю `p` (разыменование)

```go
func doubleValue(val int) {
    val = val * 2  // изменяет КОПИЮ, оригинал не тронут
}

func doublePointer(val *int) {
    *val = *val * 2  // изменяет ОРИГИНАЛ через указатель
}

func main() {
    amount := 100

    doubleValue(amount)
    fmt.Println(amount)   // 100 — не изменился!

    doublePointer(&amount)
    fmt.Println(amount)   // 200 — изменился!
}
```

### Визуально: стек и куча

```
 Стек (Stack)               Куча (Heap)
┌─────────────┐
│ amount = 100│ ◄──── обычная переменная, живёт в стеке
├─────────────┤
│ ptr = 0xC42 │ ──────► 0xC42: 100   ◄── указатель ведёт в кучу
└─────────────┘
```

В Metapus указатели используются повсеместно: методы на структурах обычно принимают `*T` (pointer receiver), чтобы изменять объект на месте, а не копировать его целиком.

## 9. Структуры (Struct) и Методы

### Структуры — аналог объектов конфигурации

В 1С Справочник.Номенклатура имеет фиксированные реквизиты: Наименование, Код, ЕдиницаИзмерения и т.д. В Go аналог — `struct`:

```go
type Item struct {
    ID          string    // Экспортное (публичное) поле — с большой буквы
    Name        string
    Code        string
    UnitID      string
    isDeleted   bool      // приватное поле — с маленькой буквы (доступно только внутри пакета)
}
```

> [!IMPORTANT]
> **Заглавная буква = публичное (экспортное).** Маленькая буква = приватное (только внутри пакета).
> Это единственный механизм «видимости» в Go. Нет ключевых слов `public`/`private`.
>
> **Где посмотреть:** откройте любую модель в `internal/domain/` — например, структуру `CatalogService` в файле `internal/domain/service.go`. Обратите внимание, какие поля экспортные, а какие нет.

### Методы — поведение, привязанное к структуре

В 1С поведение справочника описывается в «Модуле Объекта». В Go — через **методы**:

```go
// Метод с value receiver (копия объекта, не изменяет оригинал)
func (i Item) FullName() string {
    return fmt.Sprintf("[%s] %s", i.Code, i.Name)
}

// Метод с pointer receiver (изменяет оригинал)
func (i *Item) MarkDeleted() {
    i.isDeleted = true
}

func main() {
    item := Item{Name: "Молоток", Code: "00001"}
    fmt.Println(item.FullName())  // [00001] Молоток

    item.MarkDeleted()
    // item.isDeleted теперь true
}
```

> [!TIP]
> **Когда использовать `*T` (pointer receiver)?**
> - Если метод **изменяет** поля структуры → обязательно `*T`
> - Если структура **большая** (много полей) → `*T` экономит память на копировании
> - В Metapus почти все методы используют `*T`. Это наша конвенция.

## 10. Встраивание (Embedding) — аналог «наследования»

В 1С нет наследования, но есть общие реквизиты. В Go нет классического наследования (как в Java/C#), но есть **встраивание** (embedding) — когда одна структура «включает» другую, получая все её поля и методы:

```go
// Базовая структура (как набор общих реквизитов)
type BaseEntity struct {
    ID        string
    CreatedAt time.Time
    UpdatedAt time.Time
    Version   int  // для оптимистичных блокировок
}

// Структура-наследник встраивает BaseEntity
type Item struct {
    BaseEntity          // ← встраивание (без имени поля!)
    Name       string
    Code       string
}

func main() {
    item := Item{
        BaseEntity: BaseEntity{ID: "abc-123", Version: 1},
        Name:       "Молоток",
        Code:       "00001",
    }

    // Поля BaseEntity доступны напрямую — как будто они поля Item!
    fmt.Println(item.ID)        // abc-123
    fmt.Println(item.Version)   // 1
    fmt.Println(item.Name)      // Молоток
}
```

> [!IMPORTANT]
> **Где посмотреть в Metapus:**
> Наша архитектура строится на встраивании (Правило §4). Все справочники встраивают `BaseCatalog`, все документы — `BaseDocument`. Откройте любой файл модели в `internal/domain/catalogs/` или `internal/domain/documents/` и найдите строку вида `entity.BaseCatalog` или `entity.BaseDocument` — это именно встраивание.

## 11. Массивы и Срезы (Slices)

### Массивы — фиксированная длина (почти не используются)

```go
var arr [3]int = [3]int{10, 20, 30}
// arr[0] = 10, arr[1] = 20, arr[2] = 30
// Размер нельзя изменить!
```

### Срезы (Slices) — динамические массивы

В 1С аналог — `Массив`. В Go — `slice`. Вы будете использовать их постоянно:

```go
// Создание среза
users := []string{"Иванов", "Петров"}

// Добавление элемента
users = append(users, "Сидоров")

// Длина и ёмкость
fmt.Println(len(users)) // 3 — текущее количество элементов
fmt.Println(cap(users)) // 4 — текущая ёмкость (выделенная память)
```

### Устройство среза под капотом

Слайс — это не массив! Это **заголовок из трёх полей**:

```
  slice header
┌─────────────┐
│ ptr  → 0xC0 │ ──► [Иванов][Петров][Сидоров][ пусто ]
│ len  = 3    │     элемент0  элемент1  элемент2
│ cap  = 4    │
└─────────────┘
```

- `ptr` — указатель на начало массива в памяти
- `len` — сколько элементов реально используется
- `cap` — сколько элементов помещается в выделенный блок памяти

Когда `len == cap` и вы делаете `append`, Go выделяет новый, больший блок памяти и копирует данные.

> [!WARNING]
> **Правило Metapus (§3 — Capacity hints):**
> Если вы знаете размер результата (например, читаете N строк из базы), **всегда** выделяйте память заранее:
> ```go
> // Плохо: Go будет многократно переаллоцировать память
> var items []Item
> for rows.Next() { items = append(items, ...) }
>
> // Хорошо: одна аллокация
> items := make([]Item, 0, expectedCount)
> for rows.Next() { items = append(items, ...) }
> ```

## 12. Словари (Maps)

**Аналог в 1С:** `Соответствие`.

```go
// Создание
prices := make(map[string]float64)
prices["Молоток"] = 350.00
prices["Гвозди"] = 15.50

// Чтение с проверкой существования
price, exists := prices["Молоток"]
if exists {
    fmt.Println("Цена:", price) // 350.00
}

// Удаление ключа
delete(prices, "Гвозди")

// Перебор (порядок НЕ гарантирован!)
for key, value := range prices {
    fmt.Printf("%s: %.2f\n", key, value)
}
```

> [!CAUTION]
> **Порядок обхода `map` в Go случаен!** В отличие от 1С-коллекций, каждый `for range` по `map` может выдать ключи в разном порядке. Если нужен порядок — сортируйте ключи отдельно.

## Резюме модуля

| Концепция 1С | Аналог в Go |
|-------------|-------------|
| `Перем x;` | `var x int` или `x := 0` |
| `Если ... Тогда ... КонецЕсли` | `if ... { } else { }` |
| `Для Каждого ... Из ... Цикл` | `for _, item := range slice { }` |
| `Процедура / Функция` | `func name() returnType { }` |
| Общие реквизиты | Embedding (встраивание `BaseEntity`) |
| `Массив` | `[]T` (slice) |
| `Соответствие` | `map[K]V` |
| `Структура` (1С) | `struct` (Go) — но с фиксированными полями |
| Модуль Объекта | Методы на структуре (`func (s *MyStruct) DoWork()`) |
