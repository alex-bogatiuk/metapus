# Загрузка данных

> **TL;DR:** Справочник, объявленный через `registry.Catalog`, загружает элементы из файла XLSX или CSV: сопоставление колонок с полями, проверка без записи и загрузка целиком или никак. Строки документов (начальные остатки, цены) вставляются из Excel в табличную часть формы.
> **Тип:** Concept
> **Аудитория:** Developer

## Справочники из файла

Каждый объявленный справочник получает два маршрута ([`auto_import.go`](../../internal/infrastructure/http/v1/auto_import.go)), права — `<справочник>:create` и `<справочник>:update`:

| Маршрут | Что делает |
|---|---|
| `POST /catalog/<route>/import/preview` | Читает файл, отвечает колонками с предложенными полями (по совпадению заголовка с подписью или именем поля), полями справочника и первыми десятью строками |
| `POST /catalog/<route>/import` | Загружает файл по сопоставлению `mapping` (заголовок → поле). С `matchByCode` строка с кодом существующего элемента его обновляет, остальные поля элемента остаются. С `dryRun` проверяет все строки и ничего не записывает |

- Файл приходит в JSON (`fileName`, `content` в base64): платформа не принимает multipart, а контракты построены на JSON. До 10 МБ и 10 000 строк ([`importing`](../../internal/infrastructure/importing/table.go)).
- XLSX — первый лист книги. CSV — как сохраняет Excel: UTF-8 с BOM или без, Windows-1251, разделитель `;`, `,` или табуляция определяется по первой строке. Первая непустая строка — заголовки; пустые строки пропускаются, номер строки в ошибке — номер в файле.
- Значения читаются по типу поля: строки, числа, «да»/«нет», `types.Quantity` (запятая или точка), `types.MinorUnits` (целое число минимальных единиц), даты `ДД.ММ.ГГГГ`. Ссылка на справочник — его код или наименование (без учёта регистра, только элементы, не группы); «Группа» иерархического справочника — код или наименование группы. Ссылки на документы из файла не загружаются.
- Строка проходит тот же путь, что запись из формы: правила `binding`, `Validate`, нумерация пустого кода, хуки и журнал событий сервиса.
- Все строки выполняются в одной транзакции, каждая в своей точке сохранения, поэтому ошибка строки не мешает проверить остальные. Транзакция фиксируется, только если ни одна строка не упала и это не `dryRun`. Ответ: `created`, `updated`, `errors` (строка, колонка, причина), `applied`.

Во фронтенде пункт «Загрузить из файла…» в меню списка справочника появляется, когда у справочника есть маршрут загрузки ([`catalog-import-dialog.tsx`](../../frontend/components/shared/catalog-import-dialog.tsx)).

## Строки документов

Табличная часть формы документа принимает строки, скопированные из Excel или Google Sheets: вставка с текущей ячейки, ссылки ищутся по коду или наименованию, нераспознанное перечисляется ([`table-part-editor.tsx`](../../frontend/components/shared/table-part-editor.tsx), `lib/grid-paste.ts`). Так вводятся начальные остатки, цены и большие накладные.

## Пока нет

Загрузки справочников, зарегистрированных вручную (не через `registry.Catalog`), загрузки документов целиком из файла, фоновой загрузки больших файлов с прогрессом, сопоставления ссылок по другим полям (например, по артикулу).
