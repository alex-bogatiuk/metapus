# Навигация по полям таблицы

> **TL;DR:** Frontend содержит утилиты переноса фокуса и опцию `ReferenceField.autoAdvance`; товарный каскад заполнения в текущем приложении отсутствует.
> **Тип:** Concept
> **Аудитория:** Frontend Developer

`frontend/lib/table-field-navigation.ts` предоставляет `advanceToFirstEmptyField(row)` и навигацию по редактируемым ячейкам. Утилита ищет доступное пустое поле; заполненность reference-кнопок определяется через `data-has-value`.

`ReferenceField` поддерживает `autoAdvance={true}`: после выбора значения компонент переносит фокус вправо. По умолчанию опция выключена. Асинхронное заполнение зависимых полей должно завершиться до переноса фокуса; его реализует вызывающий сценарий.

Ранее описанные поступление товаров, `handleProductSelect`, `useDocumentLineActions`, автоподстановка единицы измерения и НДС не входят в текущую кодовую базу. Их нельзя использовать как готовый пример интеграции. При добавлении нового табличного ввода явно подключите утилиту и проверьте поведение клавиатуры.
