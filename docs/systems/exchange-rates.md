# Курсы валют: эксплуатация первой версии

> **Тип:** How-to · **Аудитория:** Admin, Developer
> **Контракт:** [Дизайн первой версии](exchange-rates-design.md)

## Для чего хранятся курсы

Курсы нужны для оценки криптовалютных остатков Portal в USD и объяснения пользователю происхождения этой оценки. Регистры ERP позволяют смотреть текущие состояния и историю без доступа к обозревателю БД. Котировки не управляют исполнением платежей, выводов и инвойсов.

История содержит наблюдения с временем провайдера, временем получения и записи. Одинаковая цена с новым временем провайдера — новое наблюдение. Несколько исправлений одного момента сохраняются как версии. Автоматической очистки нет.

## Настройка на чистом окружении

1. Создайте **новую** tenant-БД и примените исходные миграции проекта. Для заполненной БД используйте [операторский перенос интеграций](../operations/integration-accounts.md); reset не нужен.
2. Выполните штатный seed. Он создаёт CoinGecko-источник и записывает его UUID в `exchangeRates.sourceId`, если источник ещё не выбран.
3. Администратор открывает «Настройки → Курсы валют» и выбирает источник CoinGecko. Валюта оценки — USD.
4. В «Справочники → Интеграции» создайте аккаунты CoinGecko Demo с постоянными ключами и упорядоченный пул. В «Деньги → Источники курсов» выберите этот пул, включите источник, установите `rateLimitRpm` и задайте соответствия, например USDT → `tether`, BTC → `bitcoin`, ETH → `ethereum`. Ключи шифруются в tenant-БД и не возвращаются в API. Используется Demo endpoint `https://api.coingecko.com/api/v3/simple/price` и заголовок `x-cg-demo-api-key`. Ротация аккаунтов сохраняет источник и происхождение курсов. Подробности — [эксплуатация интеграций](../operations/integration-accounts.md).
5. Одна валюта Metapus может обслуживать токены в нескольких сетях.
6. Откройте «Деньги → Курсы валют». После следующего получения появятся курс, три времени, версия и история. Новое соответствие подхватывается без рестарта worker.

Загрузка выполняется каждые 5 минут, актуальность — меньше 15 минут от timestamp CoinGecko. Эти параметры являются серверными константами. Лимит запросов применяется к одному источнику; при использовании одного Demo-ключа несколькими tenant учитывайте их суммарное потребление квоты провайдера.

## Диагностика

| Состояние | Что проверить |
|---|---|
| Источник не выбран | `exchangeRates.sourceId` в административных настройках |
| Соответствие не настроено | Связь валюты с CoinGecko ID в форме источника |
| У токена не указана валюта | `currencyId` в справочнике токенов |
| Курс ещё не получен | Следующий запуск и журнал worker |
| Соответствие изменилось | Дождаться получения по новой версии; история старого ID сохранена |
| Источник/соответствие выключены | Активность нужных настроек |
| Курс устарел | Возраст timestamp провайдера; последняя успешная загрузка сама по себе не гарантирует свежесть |
| Не настроен ключ | Пул выбранного источника, активность аккаунтов и настроенные ключи |
| HTTP 429 | `Retry-After` и квота ключа |
| Ошибка цены или времени | Диагностика пары; валидные пары того же ответа сохраняются |

Состояние загрузки в форме источника показывает последнюю попытку, последний пригодный результат и пять счётчиков. Ошибка последнего HTTP-запроса не отменяет ещё свежую котировку. «Обновить список» перечитывает БД, не запускает загрузку. Команд принудительной загрузки и очереди нет.

## Права

Чтение регистра: `register:exchange_rate:read` (admin, accountant, manager, user в seed). Технические настройки: `catalog:rate_source:read`; изменение привязки и соответствий: дополнительно `catalog:rate_source:update`. Ключи меняются с правом `catalog:integration_account:update` и штатным step-up. Выбор источника — существующая административная граница системных настроек. Portal получает только доступные мерчанту токены и происхождение использованной оценки, без настроек и ключа провайдера.

## Проверка изолированного окружения

Используйте отдельный PostgreSQL-контейнер/кластер с новой БД. Передайте его DSN через `METAPUS_TEST_MIGRATION_DSN` для теста исходных миграций и `METAPUS_TEST_EXCHANGE_RATES_DSN` для целевых тестов. Целевые тесты создают собственные новые БД в этом кластере (учётной записи нужно право CREATE DATABASE), поэтому пакеты можно запускать параллельно. Тестовые БД сохраняются для диагностики до удаления изолированного контейнера. Не используйте DSN заполненного tenant. HTTP-ответы CoinGecko в тестах возвращает локальный `httptest.Server`; реальный ключ не нужен.

```powershell
go test -tags integration ./internal/infrastructure/storage/postgres/migration -run TestRunAllFreshCryptoLifecycleSchema -count=1
go test -tags integration ./internal/infrastructure/storage/postgres/register_repo -run TestExchangeRate -count=1
go test -tags integration ./internal/infrastructure/rate_feed -run TestRateWorker -count=1
go test -tags integration ./internal/content -run TestExchangeRate -count=1
```

Для UI выберите свободный порт через `E2E_FRONTEND_PORT` и выполните из `frontend`:

```powershell
npx playwright test tests/exchange-rates.spec.ts --workers=1
```

Сценарии Playwright подменяют API локальными ответами и не записывают данные tenant. Перед поставкой также обязательны build, lint, `go test -short -race ./...`, TypeScript и ESLint.
