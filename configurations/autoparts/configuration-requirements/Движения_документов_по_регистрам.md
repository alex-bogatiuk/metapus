# Спецификация движений документов по регистрам (1С:УНФ 3.0)
## Контур: Автоматизация магазина автозапчастей и автосервиса

Настоящий документ содержит исчерпывающее техническое описание движений всех документов учетного контура магазина автозапчастей. ## Общие архитектурные принципы проведения в УНФ 3.0

1. **Разделение складского и стоимостного учета запасов**:
   - `РегистрНакопления.ЗапасыНаСкладах` — хранит только **количественные физические остатки** в разрезах: `Склад`, `Номенклатура`, `Характеристика`, `Серия`, `Ячейка`. Не содержит сумм.
   - `РегистрНакопления.Запасы` — хранит **количественно-суммовой баланс** организации по счетам учета (`СчетУчета`), партиям (`Партия`) и привязке к заказам (`ЗаказПокупателя`). Используется для расчета себестоимости списания (по средней или FIFO).
2. **Резервирование под заказ**:
   - Резерв под заказ покупателя отражается в регистре `Запасы` заполнением измерения `ЗаказПокупателя`. Свободный остаток на складе рассчитывается как: `Остаток(ЗапасыНаСкладах) - Резерв(Запасы с заполненным ЗаказПокупателя)`.
3. **Статусная модель заказов**:
   - Движения по регистрам `ЗаказыПокупателей` и `ЗаказыПоставщикам` формируются только тогда, когда документ находится в рабочем состоянии (не является черновиком или закрытым/отмененным).
4. **Контроль взаиморасчетов**:
   - Расчеты с клиентами и поставщиками ведутся в оперативных регистрах `РасчетыСПокупателями` и `РасчетыСПоставщиками` в разрезе договоров, заказов и расчетных документов.

## Блок 1. Продажи и работа под заказ

### 1.1. ЗаказПокупателя (Стандартный)
* **Назначение**: Прием заказа от розничного или оптового покупателя на автозапчасти. Фиксация потребности, резервирование наличия на складе или запуск процесса закупки «под заказ».
* **Условие проведения**: Состояние заказа (`СостояниеЗаказа`) имеет статус с признаком «В работе» или «Выполнен».

#### Движения по регистрам:

#### 1. `РегистрНакопления.ЗаказыПокупателей`
* **Вид движения**: `Приход` (+)
* **Условие**: Для всех строк ТЧ `Запасы` и `РаботыИУслуги` (где тип номенклатуры = Запас или Работа/Услуга).
* **Поля записи**:
  | Поле регистра | Источник / Значение |
  | :--- | :--- |
  | `Организация` | `Шапка.Организация` |
  | `ЗаказПокупателя` | `Ссылка` (текущий документ) |
  | `Номенклатура` | `ТЧ.Номенклатура` |
  | `Характеристика`| `ТЧ.Характеристика` |
  | `Склад` | `ТЧ.Склад` (если не заполнен — `Шапка.Склад`) |
  | **Ресурс** `Количество` | `ТЧ.Количество` |

#### 2. `РегистрНакопления.Запасы` (Резервирование из свободного остатка)
* **Вид движения**: Две записи (`Расход` со свободного остатка + `Приход` в резерв под данный заказ).
* **Условие**: В строке ТЧ `Резерв > 0`.
* **Запись 1 (Снятие со свободного остатка)**:
  - Вид: `Расход` (-)
  - `Организация` = `Шапка.Организация`
  - `СтруктурнаяЕдиница` = `ТЧ.Склад` (или `Шапка.Склад`)
  - `Номенклатура` = `ТЧ.Номенклатура`
  - `Характеристика` = `ТЧ.Характеристика`
  - `ЗаказПокупателя` = `ЗНАЧЕНИЕ(Документ.ЗаказПокупателя.ПустаяСсылка)` (свободный остаток)
  - `СчетУчета` = `ТЧ.Номенклатура.СчетУчетаЗапасов` (обычно 41.01)
  - **Ресурс** `Количество` = `ТЧ.Резерв`
  - **Ресурс** `Сумма` = `0` (в заказе резервируется только количество)
* **Запись 2 (Постановка в резерв под заказ)**:
  - Вид: `Приход` (+)
  - Все измерения те же, кроме: `ЗаказПокупателя` = `Ссылка` (текущий заказ).
  - **Ресурс** `Количество` = `ТЧ.Резерв`

#### 3. `РегистрНакопления.ПотребностьВЗапасах`
* **Вид движения**: `Приход` (+)
* **Условие**: Если `ТЧ.Количество > ТЧ.Резерв` (требуется обеспечить / заказать у поставщика).
* **Поля**:
  - `Организация` = `Шапка.Организация`
  - `Номенклатура` = `ТЧ.Номенклатура`
  - `Характеристика` = `ТЧ.Характеристика`
  - `Склад` = `Шапка.Склад`
  - **Ресурс** `Количество` = `ТЧ.Количество - ТЧ.Резерв`

#### 4. `РегистрСведений.ИсторияСостоянийЗаказов`
* **Поля**: `Период` = `Дата`, `Заказ` = `Ссылка`, `Состояние` = `Шапка.СостояниеЗаказа`, `Ответственный` = `Шапка.Ответственный`.

---

### 1.2. ЗаказПокупателя (Вид операции: Заказ-наряд)
* **Назначение**: Комплексное обслуживание на СТО при магазине (установка купленных запчастей, ТО, ремонт).
* **Условие проведения**: `ВидОперации = ВидОперацииЗаказПокупателя.ЗаказНаряд` И состояние заказа = `Закрыт` / `Выполнен`.

#### Движения по регистрам:

#### 1. `РегистрНакопления.ЗаказыПокупателей`
* **Вид движения**: `Расход` (-) — закрытие потребности по заказу-наряду.
* `Количество` = `ТЧ.Запасы.Количество` + `ТЧ.Работы.Количество`.

#### 2. `РегистрНакопления.ЗапасыНаСкладах` (Списание деталей с полок)
* **Вид движения**: `Расход` (-)
* **Условие**: Для строк ТЧ `Запасы` (запчасти магазина).
* **Поля**:
  - `СтруктурнаяЕдиница` = `ТЧ.Склад` (или склад зоны сервиса)
  - `Номенклатура` = `ТЧ.Номенклатура`
  - `Характеристика` = `ТЧ.Характеристика`
  - `СерияНоменклатуры` = `ТЧ.Серия`
  - `Ячейка` = `ТЧ.Ячейка`
  - **Ресурс** `Количество` = `ТЧ.Количество`

#### 3. `РегистрНакопления.Запасы` (Списание себестоимости деталей)
* **Вид движения**: `Расход` (-)
* `Организация` = `Шапка.Организация`, `СтруктурнаяЕдиница` = `ТЧ.Склад`, `Номенклатура` = `ТЧ.Номенклатура`, `ЗаказПокупателя` = `Ссылка`.
* **Ресурс** `Количество` = `ТЧ.Количество`, **Ресурс** `Сумма` = `СебестоимостьСписания` (по FIFO/средней).

#### 4. `РегистрНакопления.Продажи` (Выручка и маржа)
* **Вид движения**: Оборот (формируется по ТЧ `Запасы` и ТЧ `Работы`).
* **Поля**:
  - `Организация` = `Шапка.Организация`
  - `Номенклатура` = Строка номенклатуры (запчасть или авторабота)
  - `Характеристика` = `ТЧ.Характеристика`
  - `ЗаказПокупателя` = `Ссылка`
  - `Подразделение` = `Шапка.Подразделение`
  - **Ресурс** `Количество` = `ТЧ.Количество`
  - **Ресурс** `Сумма` = `ТЧ.Сумма` (с учетом скидок)
  - **Ресурс** `Себестоимость` = Для запчастей — фактическая себестоимость списания; для работ — прямые затраты.

#### 5. `РегистрНакопления.РасчетыСПокупателями` (Долг клиента за наряд)
* **Вид движения**: `Приход` (+)
* **Поля**:
  - `Организация` = `Шапка.Организация`
  - `Контрагент` = `Шапка.Контрагент`
  - `Договор` = `Шапка.Договор`
  - `Заказ` = `Ссылка`
  - `Документ` = `Ссылка`
  - **Ресурс** `Сумма` = `Шапка.СуммаДокумента`

#### 6. `РегистрНакопления.СдельныеНаряды` (Выработка мастеров СТО)
* **Вид движения**: `Приход` (+)
* **Условие**: Для строк ТЧ `Исполнители / Работы`.
* **Поля**:
  - `Организация` = `Шапка.Организация`
  - `СтруктурнаяЕдиница` = `Шапка.Подразделение`
  - `Исполнитель` = `ТЧ.Сотрудник` (автомеханик/слесарь)
  - `Операция` / `Номенклатура` = `ТЧ.Работа`
  - `ЗаказПокупателя` = `Ссылка`
  - **Ресурс** `НормоЧасы` = `ТЧ.НормоЧасы * ТЧ.Количество`
  - **Ресурс** `КоличествоФакт` = `ТЧ.Количество`

### 1.3. РасходнаяНакладная
* **Назначение**: Фактическая отгрузка и выдача купленных автодеталей оптовому покупателю или розничному самовывозу из интернет-магазина.

#### Движения по регистрам:
1. `РегистрНакопления.ЗаказыПокупателей` (`Расход`):
   - Если указан `Шапка.ЗаказПокупателя`. Списывает отгруженное количество по заказу: `Количество = ТЧ.Запасы.Количество`.
2. `РегистрНакопления.ЗапасыНаСкладах` (`Расход`):
   - `Склад` = `ТЧ.Склад`, `Номенклатура` = `ТЧ.Номенклатура`, `Характеристика` = `ТЧ.Характеристика`, `Ячейка` = `ТЧ.Ячейка`.
   - `Количество` = `ТЧ.Количество`.
3. `РегистрНакопления.Запасы` (`Расход`):
   - Списание балансовой себестоимости: `ЗаказПокупателя` = `Шапка.ЗаказПокупателя` (если отгрузка из резерва) либо пустая ссылка (если отгрузка из свободного остатка).
   - `Количество` = `ТЧ.Количество`, `Сумма` = `СуммаСебестоимости`.
4. `РегистрНакопления.Продажи` (Оборот):
   - `Номенклатура` = `ТЧ.Номенклатура`, `Количество` = `ТЧ.Количество`, `Сумма` = `ТЧ.Сумма`, `Себестоимость` = `СуммаСебестоимости`.
5. `РегистрНакопления.РасчетыСПокупателями` (`Приход`):
   - `Контрагент` = `Шапка.Контрагент`, `Договор` = `Шапка.Договор`, `Документ` = `Ссылка`. `Сумма` = `Шапка.СуммаДокумента`.

### 1.4. КорректировкаРеализации
* **Назначение**: Возврат запчасти от покупателя (не подошла, брак, отказ), исправление цены или количества.
* **Логика движений**:
  - `ЗапасыНаСкладах` (`Приход`): возврат физической детали на склад/ячейку.
  - `Запасы` (`Приход`): восстановление себестоимости товара на балансе.
  - `Продажи` (Оборот со знаком минус): сторнирование выручки и себестоимости.
  - `РасчетыСПокупателями` (`Расход`): уменьшение задолженности покупателя (или возникновение нашего долга перед ним).

---

### 1.5. СчетНаОплату
* **Назначение**: Предварительный документ для безналичной оплаты.
* **Движения**:
  - `РегистрНакопления.ПлатежныйКалендарь` (`Приход`): планируемое поступление ДС (для отчета о кассовых разрывах).
  - `РегистрНакопления.ОплатаСчетовИЗаказов` (`Приход`): контроль статуса оплаты счета.
  - *Не делает движений по товарным регистрам!*

## Блок 2. Закупки и дистрибуция запчастей

### 2.1. ЗаказПоставщику
* **Назначение**: Заказ деталей у дистрибьютора (Армтек, Берг, Автопитер и др.) под складской запас или под конкретный заказ клиента.

#### Движения по регистрам:

#### 1. `РегистрНакопления.ЗаказыПоставщикам`
* **Вид движения**: `Приход` (+)
* **Поля**:
  - `Организация` = `Шапка.Организация`
  - `ЗаказПоставщику` = `Ссылка`
  - `Номенклатура` = `ТЧ.Запасы.Номенклатура`
  - `Характеристика` = `ТЧ.Запасы.Характеристика`
  - `Склад` = `Шапка.Склад`
  - **Ресурс** `Количество` = `ТЧ.Запасы.Количество`

#### 2. `РегистрНакопления.РазмещениеЗаказов` (Связка «Заказ клиента» <-> «Заказ поставщику»)
* **Вид движения**: `Приход` (+)
* **Условие**: В строке ТЧ указан `ЗаказПокупателя` (деталь заказана персонально под клиента).
* **Поля**:
  - `ЗаказПокупателя` = `ТЧ.ЗаказПокупателя`
  - `Номенклатура` = `ТЧ.Номенклатура`
  - `Характеристика` = `ТЧ.Характеристика`
  - `ИсточникОбеспечения` = `Ссылка` (текущий ЗаказПоставщику)
  - **Ресурс** `Количество` = `ТЧ.Количество`

#### 3. `РегистрНакопления.ГрафикДвиженияЗапасов`
* Фиксация ожидаемой даты поступления деталей на склад.

---

### 2.2. ПриходнаяНакладная
* **Назначение**: Фактическое оприходование автозапчастей от поставщика на склад.

#### Движения по регистрам:

#### 1. `РегистрНакопления.ЗаказыПоставщикам`
* **Вид движения**: `Расход` (-)
* **Условие**: Если накладная оформлена по `ЗаказПоставщику`.
* Списывает количество: `Количество = ТЧ.Запасы.Количество`.

#### 2. `РегистрНакопления.ЗапасыНаСкладах` (Физическое поступление)
* **Вид движения**: `Приход` (+)
* **Поля**:
  - `Организация` = `Шапка.Организация`
  - `СтруктурнаяЕдиница` = `ТЧ.Склад` (или `Шапка.Склад`)
  - `Номенклатура` = `ТЧ.Номенклатура`
  - `Характеристика` = `ТЧ.Характеристика`
  - `СерияНоменклатуры` = `ТЧ.Серия`
  - `Ячейка` = `ТЧ.Ячейка` (первичное распределение по полкам)
  - **Ресурс** `Количество` = `ТЧ.Количество`

#### 3. `РегистрНакопления.Запасы` (Оценка стоимости на балансе)
* **Вид движения**: `Приход` (+)
* **Поля**:
  - `Организация` = `Шапка.Организация`
  - `СтруктурнаяЕдиница` = `ТЧ.Склад`
  - `Номенклатура` = `ТЧ.Номенклатура`
  - `Характеристика` = `ТЧ.Характеристика`
  - `Партия` = `ТЧ.Партия` (или созданная партия документа)
  - `ЗаказПокупателя` = `ТЧ.ЗаказПокупателя` (если деталь поступила под заказ клиента — она **сразу встает в резерв**)
  - `СчетУчета` = `ТЧ.Номенклатура.СчетУчетаЗапасов` (41.01)
  - **Ресурс** `Количество` = `ТЧ.Количество`
  - **Ресурс** `Сумма` = `ТЧ.Сумма` (без НДС, если НДС принимается к вычету, или с НДС при УСН/патенте)

#### 4. `РегистрНакопления.РасчетыСПоставщиками` (Кредиторская задолженность)
* **Вид движения**: `Приход` (+)
* **Поля**:
  - `Контрагент` = `Шапка.Контрагент`
  - `Договор` = `Шапка.Договор`
  - `Документ` = `Ссылка`
  - `Заказ` = `Шапка.ЗаказПоставщику`
  - **Ресурс** `Сумма` = `Шапка.СуммаДокумента`

#### 5. `РегистрНакопления.Закупки` (Статистика объемов закупа)
* **Вид движения**: Оборот. `Номенклатура`, `Контрагент`, `Количество`, `Сумма`.

---

### 2.3. ДополнительныеРасходы
* **Назначение**: Увеличение себестоимости закупленных автозапчастей на стоимость доставки транспортной компанией (СДЭК, Деловые Линии и др.).

#### Движения по регистрам:
1. `РегистрНакопления.Запасы` (`Приход`):
   - Распределяет сумму расходов по позициям номенклатуры (пропорционально количеству или сумме закупки).
   - **Ресурс** `Сумма` = `РаспределеннаяДоляРасхода`, **Ресурс** `Количество` = `0` (только удорожание себестоимости единицы!).
2. `РегистрНакопления.РасчетыСПоставщиками` (`Приход`):
   - Начисление задолженности перед транспортной компанией: `Контрагент` = Перевозчик, `Сумма` = Сумма доставки.

---

### 2.4. КорректировкаПоступления
* **Назначение**: Недовоз, пересорт или изменение цен поставщиком задним числом.
* Формирует корректирующие записи в `Запасы`, `ЗапасыНаСкладах` и `РасчетыСПоставщиками`.

---

### 2.5. СчетНаОплатуПоставщика
* **Назначение**: Регистрация платежа поставщику в платежном календаре.
* Формирует движение `РегистрНакопления.ПлатежныйКалендарь` (`Расход` будущих ДС) для предотвращения кассовых разрывов.

---

## Блок 3. Складской учет и адресное хранение (Ячейки)

### 3.1. ПеремещениеЗапасов
* **Назначение**: Перемещение деталей между центральным складом, магазином (торговым залом) и зоной СТО.

#### Движения по регистрам:
1. `РегистрНакопления.ЗапасыНаСкладах`:
   - Запись 1: `Расход` со склада-отправителя (`СтруктурнаяЕдиница = Шапка.СкладОтправитель`, `Ячейка = ТЧ.ЯчейкаОтправитель`).
   - Запись 2: `Приход` на склад-получатель (`СтруктурнаяЕдиница = Шапка.СкладПолучатель`, `Ячейка = ТЧ.ЯчейкаПолучатель`).
2. `РегистрНакопления.Запасы`:
   - Запись 1: `Расход` по складу-отправителю.
   - Запись 2: `Приход` по складу-получателю.
   - Себестоимость единицы перемещается без изменения.

---

### 3.2. ПеремещениеПоЯчейкам
* **Назначение**: Перемещение автозапчастей внутри **одного склада** с полки на полку (например, из зоны приемки в постоянную ячейку стеллажа A-04-2).

#### Движения по регистрам:

#### 1. `РегистрНакопления.ЗапасыНаСкладах`
* Формирует две записи:
  - **Запись 1 (`Расход` -)**:
    - `СтруктурнаяЕдиница` = `Шапка.Склад`
    - `Номенклатура` = `ТЧ.Номенклатура`
    - `Характеристика` = `ТЧ.Характеристика`
    - `СерияНоменклатуры` = `ТЧ.Серия`
    - `Ячейка` = `ТЧ.ЯчейкаОтправитель`
    - **Ресурс** `Количество` = `ТЧ.Количество`
  - **Запись 2 (`Приход` +)**:
    - `СтруктурнаяЕдиница` = `Шапка.Склад`
    - `Номенклатура` = `ТЧ.Номенклатура`
    - `Характеристика` = `ТЧ.Характеристика`
    - `СерияНоменклатуры` = `ТЧ.Серия`
    - `Ячейка` = `ТЧ.ЯчейкаПолучатель`
    - **Ресурс** `Количество` = `ТЧ.Количество`

> **Важно**: Документ `ПеремещениеПоЯчейкам` **НЕ** делает движений по регистру `Запасы`, так как общий суммовой баланс склада и себестоимость не меняются.

---

### 3.3. ИнвентаризацияЗапасов
* **Технический статус**: Документ **не формирует движений в регистрах**.
* **Назначение**: Сверка учетных остатков с фактическими. На основании таблицы расхождений вводятся документы:
  - При излишках -> `ОприходованиеЗапасов`.
  - При недостачах -> `СписаниеЗапасов`.

---

### 3.4. ОприходованиеЗапасов
* **Назначение**: Ввод найденных при ревизии запчастей на баланс склада.

#### Движения по регистрам:
1. `РегистрНакопления.ЗапасыНаСкладах` (`Приход`):
   - `Склад` = `Шапка.Склад`, `Ячейка` = `ТЧ.Ячейка`, `Количество` = `ТЧ.Количество`.
2. `РегистрНакопления.Запасы` (`Приход`):
   - `СчетУчета` = 41.01, `Сумма` = `ТЧ.Сумма` (оценка по учетной или рыночной стоимости).
3. `РегистрНакопления.ДоходыИРасходы` (Оборот):
   - Признание прочего дохода: `Статья = Доходы от инвентаризации`.

---

### 3.5. СписаниеЗапасов
* **Назначение**: Списание недостачи, поврежденных, разбитых деталей или просроченной автохимии.

#### Движения по регистрам:
1. `РегистрНакопления.ЗапасыНаСкладах` (`Расход`):
   - Физическое списание с полки/ячейки.
2. `РегистрНакопления.Запасы` (`Расход`):
   - Списание балансовой себестоимости по FIFO/средней.
3. `РегистрНакопления.ДоходыИРасходы` (Оборот):
   - Фиксация прочего расхода: `Статья = Недостачи и потери от порчи`.

---

## Блок 4. Розничные продажи и кассовый узел (РМК)

### 4.1. ЧекККМ
* **Назначение**: Продажа автозапчастей и автотоваров в розничном магазине за наличные или банковской картой в течение смены.

#### Движения по регистрам:
1. `РегистрНакопления.ЗапасыНаСкладах` (`Расход`):
   - Списание количества проданных деталей из торгового зала: `Склад` = `Шапка.Склад`, `Ячейка` = `ТЧ.Ячейка`, `Количество` = `ТЧ.Количество`.
2. `РегистрНакопления.ДенежныеСредстваВКассахККМ` (`Приход`):
   - Если оплата **наличными**: `КассаККМ` = `Шапка.КассаККМ`, `Сумма` = `Шапка.СуммаНаличнойОплаты`.
3. `РегистрНакопления.ОплатаПлатежнымиКартами` (`Приход`):
   - Если оплата **банковской картой / СБП**: `ЭквайринговыйТерминал` = `Шапка.ЭквайринговыйТерминал`, `Сумма` = `Шапка.СуммаБезналичнойОплаты`.
4. `РегистрНакопления.ПродажиПоДисконтнымКартам` и `ПредоставленныеСкидки`:
   - Отражение лояльности и размера скидки.

---

### 4.2. ЧекККМВозврат
* **Назначение**: Возврат запчасти покупателем в течение той же кассовой смены.
* Формирует зеркальные движения со знаком `Минус` (или обратные движения) по регистрам `ЗапасыНаСкладах`, `ДенежныеСредстваВКассахККМ`, `ОплатаПлатежнымиКартами`.

---

### 4.3. ЧекККМКоррекции
* **Технический статус**: **Не формирует записей в учетных регистрах**.
* Служит исключительно для пробития чека коррекции на фискальном накопителе ККТ в соответствии с требованиями 54-ФЗ.

---

### 4.4. ОтчетОРозничныхПродажах
* **Назначение**: Закрытие смены кассира (Z-отчет), консолидация всех чеков смены, списание себестоимости и признание выручки.

#### Движения по регистрам:
1. `РегистрНакопления.Запасы` (`Расход`):
   - Списание суммовой себестоимости всех проданных за день деталей.
2. `РегистрНакопления.Продажи` (Оборот):
   - `Номенклатура`, `Количество`, `СуммаВыручки`, `СуммаСебестоимости`.
3. `РегистрНакопления.РасчетыПоЭквайрингу` (`Приход`):
   - Задолженность банка-эквайера перед предприятием по безналичным расчетам за смену.

---

## Блок 5. Автосервис и сдельная оплата мастеров

### 5.1. СдельныйНаряд
* **Назначение**: Начисление заработной платы мастерам и автослесарям автосервиса по фактически выполненным нормам или проценту от работы.

#### Движения по регистрам:
1. `РегистрНакопления.СдельныеНаряды` (`Приход`):
   - `Исполнитель` = Мастер, `Операция` = Работа, `НормоЧасы`, `КоличествоФакт`.
2. `РегистрНакопления.РасчетыСПерсоналом` (`Приход`):

3. `РегистрНакопления.НачисленияИУдержания` (Оборот):
   - Фиксация начисления сдельной зарплаты по виду начисления `Сдельная оплата`.

## Блок 6. Денежные средства и взаиморасчеты

### 6.1. ПоступлениеНаСчет и РасходСоСчета
* **Назначение**: Безналичные поступления (оплата от покупателей, возмещение эквайринга) и списания (оплата поставщикам запчастей, аренда, налоги).

#### Движения при ПоступленииНаСчет (Оплата от покупателя):
1. `РегистрНакопления.ДенежныеСредства` (`Приход`):
   - `БанковскийСчетКасса` = `Шапка.БанковскийСчет`, `Валюта` = `Шапка.Валюта`, **Ресурс** `Сумма` = `Шапка.СуммаДокумента`.
2. `РегистрНакопления.ДвиженияДенежныхСредств` (Оборот):
   - Статья ДДС = `Поступление от покупателей`, Сумма.
3. `РегистрНакопления.РасчетыСПокупателями` (`Расход`):
   - Погашение долга покупателя: `Контрагент` = `Шапка.Контрагент`, `Договор` = `Шапка.Договор`, `Документ` = Документ расчета, `Сумма` = `Шапка.СуммаДокумента`.

#### Движения при РасходеСоСчета (Оплата дистрибьютору запчастей):
1. `РегистрНакопления.ДенежныеСредства` (`Расход`): Списание ДС с банковского счета.
2. `РегистрНакопления.ДвиженияДенежныхСредств` (Оборот): Списание по статье ДДС `Оплата поставщикам`.
3. `РегистрНакопления.РасчетыСПоставщиками` (`Расход`): Погашение нашего долга перед поставщиком запчастей.

---

### 6.2. ПоступлениеВКассу и РасходИзКассы
* **Назначение**: Наличные расчеты вне РМК (инкассация выручки из кассы ККМ в сейф, выплата зарплаты мастерам, выдача подотчетных сумм водителям/снабженцам).
* **Регистры**:
  - `РегистрНакопления.ДенежныеСредства` (`Приход` / `Расход` по кассе компании).
  - При инкассации из магазина:
    - `ДенежныеСредстваВКассахККМ` (`Расход` из операционной кассы РМК).
    - `ДенежныеСредства` (`Приход` в главную кассу организации).

---

### 6.3. Взаимозачет
* **Назначение**: Схлопывание встречных задолженностей (например, оптовый клиент одновременно поставляет запчасти или расходники; перенос задолженности с одного договора/заказа на другой).
* **Регистры**:
  - `РегистрНакопления.РасчетыСПокупателями` (`Расход` долга покупателя).
  - `РегистрНакопления.РасчетыСПоставщиками` (`Расход` долга поставщика).

## 8. Памятка разработчику по реализации подсистемы

1. **Контроль отрицательных остатков**:
   - При списании деталей в `РасходнаяНакладная`, `ЧекККМ`, `Заказ-наряд` и `ПеремещениеЗапасов` накладывается управляемая блокировка на регистры `ЗапасыНаСкладах` и `Запасы`.
   - Запрос контроля остатков должен соединять остатки из `ЗапасыНаСкладах` (физическое наличие на складе/в ячейке) и `Запасы` (наличие свободного или зарезервированного под данный заказ количества).
   - Если `Остаток < ТребуемоеКоличество` — проведение отменяется с выводом сообщения: *«Недостаточно автозапчасти [Артикул] [Наименование] на складе [Склад], ячейка [Ячейка]. Требуется: X, Доступно: Y»*.
2. **Партионный учет и расчет себестоимости**:
   - В УНФ списание себестоимости из регистра `Запасы` выполняется партионным методом. Если в настройках базы включен метод FIFO, партии списываются в хронологическом порядке документа поступления. Сумма себестоимости списывается пропорционально остатку стоимости партии.
3. **Особенность учета ячеек**:
   - Измерение `Ячейка` в регистре `ЗапасыНаСкладах` заполняется **только** для тех складов (`СтруктурныеЕдиницы`), у которых установлен признак `ЯчеистыйСклад = Истина`. Для обычных складов без адресного хранения ячейка остается пустой ссылкой.
