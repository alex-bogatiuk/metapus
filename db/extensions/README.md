# Миграции расширений

Миграции модулей расширений клиента (`extensions/<модуль>/`) лежат в `db/extensions/<модуль>/`. `cmd/scaffold` создаёт каталог модуля вместе с его кодом.

- Номера начинаются с `10000` и общие для всех модулей: повтор номера — ошибка сборки источника (`dbassets.ExtensionMigrations`).
- Модули применяются к тенанту любой конфигурации после миграций платформы и конфигурации. Их история goose — таблица `goose_db_version_extensions`.
- Каталоги встраиваются в бинарники, поэтому миграции в `extensions/<модуль>/migrations/` не применяются (проверяет `internal/architecture`).
